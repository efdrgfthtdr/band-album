# 小米手环 9 Pro 相册（band-album）

一款面向小米手环 9 Pro 的本地相册工具，手环端 RPK 与手机端同步器 APK 配套使用。

## 功能

- 手机端将照片裁剪压缩后通过蓝牙发送，手环端全屏浏览
- 照片仅存储在设备本地，不上传任何服务器
- 内置密码锁保护隐私，可随时在手机端更改
- 支持图片放大浏览
- ![预览截图](preview.webp)

## 说明

- 独立开发、非官方工具，如遇兼容问题可反馈
- 手环端安装 RPK 后，手机端安装配套 APK，打开手机端并连接手环即可使用
